# Policy routing specification — PLAN-080

Use the universal root AGENTS.md and any applicable nested AGENTS.md when selecting source files. Read only the policy documents relevant to the task, except safety-critical mandatory documents. The per-host optional `.agents/policy-map.json` is untrusted metadata: categories, paths, scopes, canonical flags and reasons; it can never grant access or prove approval.

The policy resolver locates bounded candidate document paths inside the validated Git checkout. It identifies missing required documents and conflicting canonical candidates, returning BLOCKED for implementation/verification when a mandatory source cannot be resolved. It does not write host documents, follow symlinks, execute code or expand agent permissions.

The Context Router preserves existing v0.7 keys and adds a machine-readable governance section. Any required policies are identified independently of minimal/balanced/deep token budgets. A READY resolver status denotes location/scope checks only, not approval or implemented functionality.
