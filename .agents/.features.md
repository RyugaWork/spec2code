## Windows CI regression fix (2026-11-12)

Path Guard, installed-skill configuration validation, Spec Kit feature containment and session root binding were made Windows 8.3/case-alias aware while rejecting real symlink/junction ancestors. CRLF/LF handoff files are processed with raw SHA-256 provenance retained. On CI run [43230563194](https://github.com/RyugaWork/spec2code/actions/runs/43230563194), Windows Python 3.14 ran 92 tests, PASS with zero skips. Linux Python 3.10/3.11/3.13 each ran 92 tests PASS with three intentionally skipped Windows-only tests. This does not certify Windows filesystem race-freedom or untested OneDrive/network shares.
