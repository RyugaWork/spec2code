## RISK-026 — CI compatibility versus sandbox security

GitHub Actions PASS on one Windows runner version is not proof of Windows filesystem race resistance. `scope_io.py` uses repeated checks rather than POSIX-style anchored IO on Windows; another process able to modify junctions concurrently could still introduce a TOCTOU risk. Continue treating adversarial, concurrent and OneDrive/network filesystem cases as **OPEN**. The root alias hotfix permits alternate *names* for the **same validated physical checkout**, never a filesystem symlink/junction redirection.
